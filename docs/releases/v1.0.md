# Checkpoints v1.0 — release note (draft, not tagged)

One app for the reboot01 Go, JavaScript and Rust checkpoint testers. Students sign in once with their Reboot01 username and switch between the three tracks.

## What is in it
- Track switcher and routes `/go/:slug`, `/js/:slug`, `/rust/:slug`; checkpoint → level tree with progress.
- Workbench as in the three testers: subject, editor with file tabs, args, Run, Submit, Cancel, Format (Go), autosave, reset, snapshots, stuck dialog, error explanations per language.
- One runner dispatcher for all languages: live output, queue of 3, cooldowns 30 s Run / 90 s Submit from run end, 1 MB output cap, 384 MB / 0.5 CPU per run.
- One SQLite database keyed by language; session tokens stored hashed.
- Merge script for the three live databases (tested on fake data only).
- Deploy kit: one service, nginx site for checkpoints.appsyss.com, 301 redirects from the three old subdomains, backups.

## Checked
- Build and 145 tests pass (lan_vm1).
- Every reference solution passes and every starter fails through the real runners: Rust 40/40, Go 60/60, JS 29/29.
- API smoke test per language (sign-in, Run, cooldown, Format, Submit, Cancel, attempts) passes.
- Browser click-through for Rust and JS.
