# Checkpoints v2.0 — release note (draft, not yet released)

Student features, across Go, JavaScript and Rust:
- **Dashboard** (home page): progress per track, gates, Resume, recent activity. Tracks are chosen here; the workbench sidebar no longer has a track switcher.
- **History**: every Run and Submit, with filters, and the code and output of each one.
- **Solutions**: your last passing copy of each exercise, and a one-exercise **Markdown report** (subject, provided files, your solution, result).
- **Preferences**: font size, tab size, word wrap, Default or Vim keys, saved to your account. Dark theme only.
- **Sidebar**: private stars, search, status filter (not started / in progress / passed / starred), a collapsible rail.
- **Phones and tablets**: one pane at a time (Exercises, Subject, Code, Output), a symbol bar with undo/redo, plain-text output.
- **Offline**: a banner, Run/Submit wait, and edits are kept in the browser and saved when the connection returns.
- **Hardening**: Go runs with a read-only root filesystem.

Cooldowns: 15 s after Run, 60 s after Submit, one shared wait.
