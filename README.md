# Reboot01 Checkpoint Testers: Go, JavaScript & Rust

Free, browser-based **checkpoint testers** for the **reboot01** main program. Practise the **Go checkpoint**, **JavaScript (JS) checkpoint** and **Rust checkpoint** exercises online. There is nothing to install: pick an exercise, write your solution in the browser, and submit it.

## Checkpoint testers

| Language | Link |
| --- | --- |
| **Go** checkpoint tester | https://go-checkpoints.appsyss.com/ |
| **JavaScript** checkpoint tester | https://js-checkpoints.appsyss.com/ |
| **Rust** checkpoint tester | https://rust-checkpoints.appsyss.com/ |

## How it works

1. Open the tester for your language (Go, JavaScript or Rust).
2. Sign in with your **reboot01 username** (not your email) and your reboot01 password.
3. Pick a checkpoint exercise.
4. Write your solution in the browser editor and submit it to see the result.

It works on any machine with a browser, so you can practise before checkpoint day.

## Who is this for?

Students in the **reboot01** program (including the piscine) who want to practise the **Go**, **JS / JavaScript** and **Rust** checkpoints.
